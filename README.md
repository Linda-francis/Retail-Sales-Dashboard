# Retail Sales Dashboard

## Overview
This project is an interactive Retail Sales Dashboard developed using Microsoft Excel to analyze retail sales data and generate business insights.

## Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Slicers
- Timelines

## Features
- Interactive sales dashboard
- Sales, Profit, and Orders analysis
- Regional and Category-wise performance
- Monthly sales trends
- KPI visualization

## Skills Demonstrated
- Data Cleaning
- Data Transformation
- Dashboard Development
- Data Visualization
- KPI Analysis
